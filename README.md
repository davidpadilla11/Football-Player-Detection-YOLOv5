# Football Player Detection with YOLOv5

This project explores football player and ball detection using YOLOv5 in a Jupyter Notebook environment.

The work was developed as part of an Artificial Intelligence laboratory assignment focused on creating a functional local environment with Docker and Jupyter Notebook, executing `.pt` models, testing object detection on football images, and analyzing the obtained results.

The laboratory topic was open-ended, and I decided to focus the project on football-related computer vision tasks because of my personal interest in sports analytics and image recognition.

The project was based on open-source YOLOv5 resources and Kaggle examples used for educational and learning purposes.

---

## Laboratory Objectives

- Configure a local environment using Docker and Jupyter Notebook.
- Understand the use of `.pt` models in computer vision.
- Execute inference on football images selected for testing and analysis.
- Test player detection, ball detection, and basic team classification.
- Analyze metrics, graphs, and outputs generated during notebook execution.

---

## Technologies Used

- Python
- YOLOv5
- PyTorch
- OpenCV
- Jupyter Notebook
- Docker

---

## Features

- Football player detection
- Ball detection
- Basic team classification (`Team1` and `Team2`)
- Testing with football match images from different scenarios
- Inference execution using pretrained `.pt` weights

---

## Training Configuration

During the laboratory work, different execution and training parameters were configured and tested, including:

- Number of epochs
- Batch size
- Image resolution
- Dataset configuration through `.yaml` files
- Usage of pretrained weights (`yolov5s.pt`)

The notebook also included training metrics and performance graphs originally provided in the Kaggle reference notebook. These graphs were analyzed as part of the learning process in order to better understand model behavior, training performance, and inference results.

---

## Dataset and Inspiration

This project was developed using publicly available educational and open-source resources.

### References

- YOLOv5 Open Source Implementation
- Kaggle Football Analysis Dataset
- Kaggle YOLOv5 Football Detection Notebook

---

## Results

Several tests were performed using football images from different matches and scenarios.

The obtained results allowed:

- Detection of multiple players on the field
- Ball detection in different situations
- Basic differentiation between teams based on jersey colors
- Analysis of successful detections and model limitations caused by lighting conditions, distance, and similar uniform colors
